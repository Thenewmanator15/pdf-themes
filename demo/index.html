About this viewer

This is a proof of concept for a proposal to the PDF Association, and the draft specification is on GitHub. No PDF reader supports themes yet, so this page does the reader's part itself, with pdf-lib to swap a theme's objects and pdf.js to draw the page. To see a theme in any other reader, download the file and save that theme as a plain PDF with pdf-themes apply.

If themed PDFs are new to you, Why themes belong inside the PDF explains the idea in plain words, and the evidence gives the studies behind it. The rest of this page is a working viewer for themed PDFs.

Each document here is a single PDF with its content stored once and its colour themes inside it. This page loads the themes it finds in the file and does what a theme-aware reader would. It swaps the objects a theme lists, paints the theme's paper colour and draws the page. The first document is the proposal itself, a tagged file that passes veraPDF's automated checks for PDF/A-2a and PDF/UA-1. In the proposal, the theme lab, the objects test and the figure, every theme is one the author built from the source, plots and all. In the test document and the test page only light and dark were built, and the other six were worked out by the tool; the scanned page was built once, and its other seven themes were worked out from the scan. Any PDF reader today shows the light colours.
