# Assets

- `simpleBox.u3d` is the "simpleBox" test scene from the open-source U3D library
  (https://github.com/ningfei/u3d, `Samples/TestScenes/simpleBox.u3d`), released under the
  Apache License 2.0.
- `clip.mp4` and `poster.png` were made for this test with FFmpeg's `testsrc2` pattern generator.
- `tone.raw` and `tone.wav` are a 440 Hz tone generated for this test.

The photos and diagrams in the test file are drawn by the generator itself.
